📋 About ModernPDF

ModernPDF is a comprehensive, production-ready PDF processing library with first-class support for streaming and AI systems.

Key Features:

  • Single-file TypeScript library
  • Streaming-first architecture
  • AI-native with semantic chunking
  • Web Workers support
  • Universal compatibility (Node.js, browsers, edge)
  • Comprehensive PDF operations
  • Full TypeScript support

💻 Code Examples

Here's how you would use ModernPDF in your code:

Basic Usage:

import ModernPDF from 'modernpdf'; // Load PDF from file const pdf = await ModernPDF.fromFile(file); // Extract text const text = await pdf.extractText({ preserveFormatting: true, extractTables: true }); // Get metadata const metadata = pdf.getMetadata(); console.log(`Pages: ${metadata?.pageCount}`); // Clean up pdf.close();

AI Integration:

// AI-powered semantic chunking const chunks = await pdf.generateSemanticChunks({ strategy: 'semantic', maxChunkSize: 1000, preserveParagraphs: true }); // Stream to LLM for await (const chunk of pdf.streamSemanticChunks()) { await sendToLLM(chunk.content); }
