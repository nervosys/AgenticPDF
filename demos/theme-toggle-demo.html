NeoPDF Theme Toggle Configuration

The theme toggle functionality is now built into the NeoPDF library as part of the optimal configuration.

✨ New Features in NeoPDF

  • Theme Toggle Support - Built-in dark/light mode switching
  • Theme Persistence - Remembers user preference across sessions
  • Auto System Detection - Detects system theme preference
  • Easy Integration - Simple API for adding theme controls
  • Customizable Storage - Configurable localStorage key
  • Observer Pattern - Subscribe to theme change events

🎛️ Enhanced RenderOptions

New theme-related options added to the RenderOptions interface:

interface RenderOptions {
  // ... existing options
  
  // Theme toggle options
  enableThemeToggle?: boolean;     // Enable theme switching
  persistTheme?: boolean;          // Save theme to localStorage
  defaultTheme?: 'dark' | 'light' | 'auto';  // Default theme
  themeStorageKey?: string;        // Custom storage key
}

🔧 Usage Examples

1. Automatic Optimal Configuration

// Theme toggle is now enabled by default
const pdf = await NeoPDF.fromFile(file);
// Automatically includes theme toggle functionality!

2. Create Complete Themed Viewer

const pdf = await NeoPDF.fromFile(file);
const container = document.getElementById('pdf-container');

// Creates viewer with theme toggle button
const viewer = pdf.createOptimalViewer(container, {
  enableThemeToggle: true,
  defaultTheme: 'dark',
  persistTheme: true
});

// Access theme manager
console.log('Current theme:', viewer.themeManager.getCurrentTheme());

3. Manual Theme Management

// Initialize theme globally
const themeManager = NeoPDF.initializeTheme({
  defaultTheme: 'auto',      // Detect system preference
  storageKey: 'my-app-theme',
  persistTheme: true
});

// Add theme change listener
themeManager.addObserver((theme) => {
  console.log('Theme changed to:', theme);
});

// Programmatically change theme
themeManager.setTheme('light');

4. Create Standalone Theme Toggle Button

// Create theme toggle button anywhere
const themeButton = ThemeManager.createThemeToggleButton({
  size: 'large',
  position: 'fixed',
  className: 'my-theme-btn'
});

document.body.appendChild(themeButton);

🎨 CSS Integration

The ThemeManager automatically applies classes to the body element:

/* Dark mode (default) */
body { /* No class added */ }

/* Light mode */
body.light-mode {
  background: #f5f5f5;
  color: #333;
}

/* Your CSS can respond to theme changes */
.pdf-viewer {
  background: var(--viewer-bg, #111);
  transition: background-color 0.3s ease;
}

body.light-mode .pdf-viewer {
  --viewer-bg: #e9ecef;
}

🔄 Migration Guide

Existing NeoPDF code will continue to work unchanged:

✅ Fully Backward Compatible
No breaking changes to existing APIs or functionality.

To Enable Theme Toggle in Existing Projects:

  1. No changes needed - theme toggle is enabled by default
  2. Add CSS for .light-mode class (optional)
  3. Use pdf.createOptimalViewer() for complete themed viewer
  4. Access theme manager with NeoPDF.getThemeManager()

💡 Best Practices

  • Use enableThemeToggle: true for interactive applications
  • Set defaultTheme: 'auto' to respect system preferences
  • Always include CSS for both light and dark modes
  • Use theme observers for complex UI updates
  • Test theme switching with your specific content
  • Consider accessibility when designing theme styles
